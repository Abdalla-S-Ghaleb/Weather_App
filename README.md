# 🌤️ Weather App

A simple Python weather application that displays the current temperature and weather conditions for a city entered by the user.

## Features

* 🔎 Search weather by city
* 🌡️ Display temperature
* ☁️ Display weather condition and icon
* 🔐 Secure API key using environment variables

## Technologies

* Python
* Tkinter
* Requests
* OpenWeather API
